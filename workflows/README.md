# GradeManager Workflows

Use these workflow documents when setting up or operating production integrations.

## Available Workflows

- [Provision a School](school-provisioning.md): Create or update a school and its first School Admin account.
- [Configure Cloudflare Email](cloudflare-email.md): Set up access-code and invite email delivery through Cloudflare.
- [Configure Cloudflare R2](cloudflare-r2.md): Store production profile photos on Cloudflare R2.
- [Configure Paystack Dues](paystack-dues.md): Route student dues to adviser payout accounts through Paystack subaccounts.

## Operating Rule

Keep one workflow per file. If a setup process grows beyond a few steps or has its own credentials, environment variables, or verification checklist, document it in a dedicated file under this directory.
